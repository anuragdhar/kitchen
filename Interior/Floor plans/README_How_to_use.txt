RECOMMENDED FREE SOFTWARE:
--------------------------
**Best choice: Sweet Home 3D** (completely free & open source)
- Download: https://www.sweethome3d.com
- How to use the OBJ:
  1. Open Sweet Home 3D → File → Import → Import furniture (or drag the .obj)
  2. Or better workflow for accuracy:
     - Create new project
     - Plan → Import background image → select the original floor plan PNG
     - Set the scale using a known dimension (e.g. type 4993 for the Lobby width)
     - Use the Wall tool to trace over the image (most accurate method)
     - Set wall height to 300 cm (3000 mm)
     - Then add doors, windows, furniture from the catalog

**Other free options that open .obj:**
- Blender (free) - full 3D power
- FreeCAD (free)
- MeshLab
- Online: https://3dviewer.net (just drag the .obj to view)

Notes on the model:
- Room sizes are exact as written on the original plan.
- Relative positions between rooms are approximated from the drawing.
- You may need to nudge rooms slightly in the software so walls align perfectly.
- Doors and windows are not included (add them in the SW).

# Removing old leftovers from the repository (2026-10-05)

Plain-language note for the owner, who asked: "Go through the source code, remove old artifacts if any."

Nothing in any room changed: no size, no position, no opening, no saved layout, no stored browser data and no page
looks different. Only things that nothing uses any more were taken out. Everything removed is still in the Git history
and can be brought back with one command (given at the end).

## How each item was judged

Every tracked file in the repository (864 of them) was checked for who refers to it: imports in the app, the `npm`
scripts in `package.json`, the tests, the Windows launchers and their test, the render worker and the other scripts,
the GitHub workflow, `.gitignore`, and every document. Each item then went into one of three groups:

- **Removed:** provably unused, and not a reference image, an authored model, a saved layout or historical evidence.
- **Kept:** it looks old, but something uses it or a document says to keep it.
- **Unsure:** it looks unused, but it may matter to you. These are kept and listed below for you to decide.

When in doubt, the item was kept. Untracked and ignored files (for example `tmp/`, `PatchApplied/`, `PatchFailed/`,
`patch-log.txt`, `node_modules/`) were not touched.

## Bringing something back

Every removed file is in the Git history. To restore one, run from the repository root, for example:

```
git checkout 6799838 -- react-configurator/src/rooms/lobby/LobbyNorthStorage.js
```

`6799838` is the last commit before this cleanup. For the removed code inside `App.jsx`, `drawingLighting.mjs` and
`Bedroom1Layouts.js`, `git show 6799838:<path>` prints the old file.

# Home Interior

experiments. The application starts at `react-configurator/src/main.jsx` ->
`HomeApp.jsx`; the kitchen workspace is `src/App.jsx`.

## Run

Use Node 22 (also recorded in `.nvmrc`) and npm. From the repository root:

```sh
cd react-configurator
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

Open `http://127.0.0.1:5173/` and choose a room. On Windows,
`Run-Kitchen-React-App.bat` is also available; the commands above are the explicit
reproducible setup. Do not replace the committed lockfile with another package
manager's lockfile as part of an unrelated task.

## Verify

From `react-configurator/`:

```sh
npm test
npm run check
```

`npm test` uses Node's built-in test runner without third-party dependencies.
It checks the current kitchen baseline, pure geometry checks, and inspection
helpers. `npm run check` additionally builds the application and needs `npm ci`.
GitHub Actions runs the same tests and production build on pull requests.
Neither command is a full visual or construction-safety assessment.

With the dev server running in a separate terminal:

```sh
npx playwright install chromium
npm run inspect -- --strict
npm run visual:qa
```

The browser tools navigate from the whole-home screen into the kitchen using a
fresh browser context. `inspect --strict` fails on missing API capabilities,
malformed validation results, runtime errors, or reported validation failures.
The screenshot script is a smoke check, not an approved-baseline comparison.
See [testing limitations](docs/TESTING.md) before interpreting a pass.

## Editing a design

For the implemented kitchen defaults start with
`react-configurator/src/config/kitchenConfig.js` (`KITCHEN`, `EAST_INIT`,
`WEST_INIT`, `AIRY_WEST_INIT`). An already running browser may hold a saved variant;
inspect its state before editing. Preserve stable IDs and version/migration keys.

Appearance-only changes must not move walls, openings, or appliances. Explicit
layout changes should include the before/after dimensions, the reason for changing
the baseline tests, and affected-view screenshots.

## CAD, renders, and reference assets

`freecad/`, `blender/`, `sweethome3d/`, and `coohom-export/` contain separate tools
and exports; Coohom was marked paused in the prior workflow. Consult their scripts
before regenerating anything. No CAD export was regenerated by the AI-friendly
foundation update. Generated files are not an alternative source of live geometry.

Keep original floor plans and authored assets. In particular, `HomeApp.jsx` imports
an image from `Interior/`. Only the tracked dependency backup was removed; existing
render evidence, models, and historical layouts remain available.
